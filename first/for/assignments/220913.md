# Crew selection (Bradatan Alexandru Gabriel 10658858)

## Overview

Given the following sailors, we need to select a crew such that we minimize the
overall salary while we still reach at least 15 in every skill.

| Name  | Fishing | Sailing | Navigation | Salary (k€) |
|:-----:|:-------:|:-------:|:----------:|:-----------:|
| Amy   | 3       | 5       | 1          | 46          |
| Bill  | 1       | 2       | 5          | 43          |
| Carl  | 3       | 4       | 2          | 47          |
| Dan   | 4       | 3       | 1          | 36          |
| Eva   | 4       | 2       | 2          | 43          |
| Fred  | 1       | 3       | 4          | 55          |
| Greg  | 3       | 1       | 5          | 68          |
| Henry | 5       | 4       | 2          | 64          |
| Ida   | 3       | 3       | 3          | 60          |

## Formalization

We can formalize the problem by using 9 binary variables and the following
equations:

$$
\begin{gathered}
  min \; 46x_a + 43x_b + 47x_c + 36x_d + 43x_e + 55x_f + 68x_g + 64x_h + 60x_i \\
  3x_a + 1x_b + 3x_c + 4x_d + 4x_e + 1x_f + 3x_g + 5x_h + 3x_i \geq 15 \\
  5x_a + 2x_b + 4x_c + 3x_d + 2x_e + 3x_f + 1x_g + 4x_h + 3x_i \geq 15 \\
  1x_a + 5x_b + 2x_c + 1x_d + 2x_e + 4x_f + 5x_g + 2x_h + 3x_i \geq 15 \\
  x_a, x_b, x_c, x_d, x_e, x_f, x_g, x_h, x_i \in \{0, 1\}
\end{gathered}
$$

## Solution

We have a problem of combinatorial optimization. Each selection can be seen as a
subsequence of the complete list of sailors. The simplest approach to computing
the solution we can take is to enumerate all distinct subsequences, which are
$2^n = 2^9 = 512$ since we do not have repeated elements.

After enumerating every subsequences and then computing the minimum salary, we 
can see that the optimal solution is:

- Crew members: Amy, Bill, Carl, Greg, Henry
- Cost: 268 k€
- Skills:
  - Fishing: 15
  - Sailing: 16
  - Navigation: 15

The solution has been generated by using the following program, written in
Haskell:

```haskell
import Data.List
import Data.Function

data Member = Member
  { name       :: [Char],
    fishing    :: Int,
    sailing    :: Int,
    navigation :: Int,
    salary     :: Int
  }
  deriving (Show)

allMembers =
  [ Member "Amy" 3 5 1 46,
    Member "Bill" 1 2 5 43,
    Member "Carl" 3 4 2 47,
    Member "Dan" 4 3 1 36,
    Member "Eva" 4 2 2 43,
    Member "Fred" 1 3 4 55,
    Member "Greg" 3 1 5 68,
    Member "Henry" 5 4 2 64,
    Member "Ida" 3 3 3 60
  ]

tot :: (Member -> Int) -> [Member] -> Int
tot f ms = foldr (+) 0 (map f ms)

-- From the list of all the subsequences we first filter out the sequences that
-- do not satisfy our skill constraint. Then we extract the minimum of the
-- salaries
optimal :: [Member]
optimal = minimumBy compareSalaries $ filter enoughSkill (subsequences allMembers)
  where enoughSkill ms = (tot fishing ms >= 15) &&
                         (tot sailing ms >= 15) &&
                         (tot navigation ms >= 15)
        compareSalaries = compare `on` tot salary

main = do
  putStrLn $ "Optimal crew: " ++ (show $ map (\a -> name a) optimal)
  putStrLn $ "Cost: " ++ (show $ tot salary optimal)
  putStrLn $ "Fishing: " ++ (show $ tot fishing optimal)
  putStrLn $ "Sailing: " ++ (show $ tot sailing optimal)
  putStrLn $ "Navigation: " ++ (show $ tot navigation optimal)
```

## Final observations

The solution proposed here scales exponentially with the number of sailors,
which undesirable. A more efficient algorithm may be needed.
